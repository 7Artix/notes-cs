安装 `mihomo`

- 下载`deb`包, 并安装
- 准备 `config.yaml` 文件
- 准备 `Country.mmdb`

将 `yaml` 和 `mmdb` 文件复制到 `/etc/mihomo` .

将 `yaml` 中的允许访问的主机地址改为 `0.0.0.0:9090`

```shell
systemctl restart mihomo
```

使用 `http://metacubex.github.io/metacubexd/#/setup` 访问后端
或者使用 `http://metacubex.github.io/metacubexd/` , 注意一定要使用 `http` 协议访问.

终端变量配置

```shell
# 设置 HTTP 代理
export http_proxy="http://127.0.0.1:7890"
# 设置 HTTPS 代理
export https_proxy="http://127.0.0.1:7890"
# 设置所有协议（包含 FTP 等）
export all_proxy="socks5://127.0.0.1:7890"
```
