# 出现

原本的JavaScript是属于浏览器的语言, 浏览器是唯一的JavaScript语言的运行环境.

为了能够构建一个可扩展的网络服务器框架, Node.js被发明出来. 在创始人Ryan Dahl的构想中, 大型的应用程序有许多互联的小型服务器(Node)构成. Node即网络结构中的一个运行实例.

后续Node.js将Chrome浏览器中的V8引擎拆出, 变为可以在服务器运行JavaScript的环境.

至此, JavaScript语言可以通过Node.js独立于浏览器运行在服务器上.


# `node` 和 `npm`

`node` 类比 `python`, `npm` 类比 `pip`.
