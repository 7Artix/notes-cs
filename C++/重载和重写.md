
|  特征  |  重载 (Overloading)   |   重写 (Overriding)    |
| :--: | :-----------------: | :------------------: |
| 作用范围 |     同一作用域 (类内)      |     基类与派生类 (继承)      |
| 参数列表 |        必须不同         |     必须相同 (签名一致)      |
| 虚函数  |         不需要         | 基类函数必须是虚函数 `virtual` |
| 多态类型 |    静态多态 (编译期绑定)     |     动态多态 (运行期绑定)     |
|  目的  | 方便使用者, 用相同的名字处理不同类型 | 实现多台, 允许派生类提供基类的具体实现 |

若在父类的虚函数中执行了一些操作, 而用子类重写了函数, 那么父类虚函数中的操作<font color=red><b>默认不会执行</b></font>, 若需要执行, 则需要在子类中显式调用父类方法.
