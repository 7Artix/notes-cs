
```cpp
#include <iostream>
#include <random>

int main() {
    std::random_device rd; // 获取随机种子
    std::mt19937 gen(rd()); // Mersenne Twister 引擎

    std::uniform_int_distribution<> distrib(33, 126);

    std::cout << "随机生成 ASCII 字符: " << std::endl;
    for (int i = 0; i < 10; ++i) {
        // distrib(gen) 从引擎 gen 中生成一个符合分布范围的随机整数
        char random_char = static_cast<char>(distrib(gen));
        std::cout << random_char;
    }
    std::cout << std::endl;
    return 0;
}
```

`mt19937` Mersenne Twister 引擎, 是一种伪随机数生成算法, 是一个模板类, 通常省略模板参数.

使用 `mt19937` 是因为它是模板类别名:

```cpp
using mt19937=mersenne_twister_engine<unsigned int,32,624,397,31,0x9908b0df,11,0xffffffff,7,0x9d2c5680,15,0xefc60000,18,1812433253>
```

`using` 是 C++ 关键字, 作用类似 `typedef` , 区别在于 `using` 可以为模板类创建别名. 而且 `using` 的等式表达式更直观.

`gen` 是对象名, 使用 `rd()` 构造, 即使用 `random_device` 的 `operator()` **函数调用操作符**的返回值进行构造.

`uniform_int_distribution<>` 也是一个模板类, 表示整数均匀分布. 就像泛型一样.

`distrib` 是对象名, 使用类对应的构造方法进行构造.

`distrib(gen)` 是使用 `distrib` 对象的**函数调用操作符** `operator()` .

`static_cast<>` 静态类型转换, 转换为 `char` 类型.

`operator()` 是**函数对象** , 或称为**Factor**. 相较于类方法, 主要作为语法糖, 优化表示.
为了实现类的 `operator()` 需要在类中重载 `operator()` .

静态类型转换 `static_cast<>()` , 是 4 种命名转换操作符之一, 用于编译时已知, 相对安全的转换. 4 种转换分别为:
- `static_cast`
- `dynamic_cast`
- `const_cast`
- `reinterpret_cast`
