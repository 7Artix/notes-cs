
安装 `powertop` 后, 使用自动调节功能:

```shell
powertop --auto-tune
```


内核 `governor` 控制CPU频率

```shell
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor
```

`scaling_governor` 的选项包括:

- `performance` 强制CPU运行在最高主频, 响应最快但最耗电.
- `powersave` 强制CPU运行在最低主频, 最省电但性能最差.
- `schedutil` (推荐) 利用内核调度器 (PELT) 数据调整频率, 能精准匹配负载, 平衡省电与性能.
- `ondemand` 传统的动态调频，根据CPU使用率跳变频率.
- `conservative` 类似 `ondemand`, 但频率升降更平缓，更适合电池供电.
- `userspace` 允许用户态程序 (如自定义脚本) 手动设置具体频率.

可通过:

```shell
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_available_governors
```

查看支持的模式.

修改模式使用:

```shell
echo powersave > /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor
```

可用的功耗检测工具:

`htop`, `powertop`, `powerstat`, `s-tui`.

查看CPU实时频率:

```shell
# 查看所有核心的当前实时频率 (单位：kHz)
cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq
```

动态刷新查看CPU实时频率:

```shell
watch -n 1 "cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq"
```

查看CPU目前设置的最高工作频率:

```shell
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_max_freq
```

查看CPU支持的最高频率:

```shell
cat /sys/devices/system/cpu/cpu0/cpufreq/cpuinfo_max_freq
```

查看CPU支持的所有频率档位:

```shell
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_available_frequencies
```

设置单核最高频率:

```shell
echo 1800000 **>** **/sys/devices/system/cpu/cpu0/cpufreq/scaling_max_freq**
```

关核:

```shell
echo 0 > /sys/devices/system/cpu/cpu1/online
echo 0 > /sys/devices/system/cpu/cpu2/online
echo 0 > /sys/devices/system/cpu/cpu3/online
```

`htop` 等工具也可以显示实时频率.

控制GPU频率.

控制GPU功耗相关设置:

```shell
cat /sys/class/devfreq/fde60000.gpu/cur_freq
cat /sys/class/devfreq/fde60000.gpu/available_frequencies
cat /sys/class/devfreq/fde60000.gpu/available_governors
```

检查GPU负载:

```shell
cat /sys/class/devfreq/fde60000.gpu/load
```

GPU驱动分为两部分: 内核中的 `mali_kbase.ko` 和用户态的 `libEGL_mali.so`.


控制VOP显示设备:

```shell
cat /sys/class/devfreq/fe040000.vop/cur_freq
cat /sys/class/devfreq/fe040000.vop/available_frequencies
cat /sys/class/devfreq/fe040000.vop/available_governors
```

一些可控设备:

```shell
ls /sys/class/devfreq
fde60000.gpu@  fdf40000.rkvenc@  fdf80200.rkvdec@  fe040000.vop@
```

其中 `enc` 是编码器, `dec` 是解码器.

关闭DRM输出:

```shell
ls /sys/class/drm/
```

解绑fbcon:

```shell
echo 0 > /sys/class/vtconsole/vtcon1/bind
```
