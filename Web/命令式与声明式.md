# 声明式 (Declarative)

**关注结果**.

以实现一个点击按钮, 页面数字+1的功能为例.

命令式:
1. HTML编写数字放置位置
2. JS获取DOM元素 (文档对象模型), 即获取一个对象
3. 监听按钮点击事件
4. 当点击发生, 读取当前数字并+1
5. 手动将数字写回原位置, 更新DOM

声明式:
1. 声明变量
2. 通过Vue指定变量显示位置
3. 点击按钮时修改变量

使用声明式编写, 只需要修改数据 (状态), 底层引擎会**自动根据数据变化更新页面**.

声明式编写中的结构不是静态固定的, 而是动态的, 是根据数据绑定的.
