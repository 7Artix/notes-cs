
`.so` 是动态库, 是打包的二进制功能包, 当某个软件使用到这个动态库时, 会进行挂载使用.
`.so` 的核心是动态链接, 将 `.so` 挂载到进程的内存空间中使用.

使用 `ldd` 命令查看一个程序使用了哪些动态库.

使用 `nm -D` 命令查看动态库中的函数.

# 兼容性问题

使用 SONAME 机制

| 文件名类型 | 示例               | 说明            |
| :---: | ---------------- | ------------- |
| 真实文件名 | `libz.so.1.2.11` | 本体, 包含实际的库函数  |
|  逻辑名  | `libz.so.1`      | 兼容性标识, 主版本号相同 |
|  链接名  | `libz.so`        | 编译时使用         |
